# Security policy

## Scope

This security policy applies only to the limited public demo in this repository. It does not describe or expose the security architecture of the separate private NORA application.

## Important limitation

The demo has no authentication or authorization and is intended for local evaluation only. Keep the server bound to `127.0.0.1`. Do not expose it to the public internet or a shared network, and do not enter real personal, account, health or medication information.

The public demo has not undergone an independent security audit or penetration test. Its automated tests are not a security certification.

## Reporting a concern

Please do not publish credentials, personal information or an unpatched exploit in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the maintainer through the [GitHub profile](https://github.com/ArthurGuimaraess) and share only the minimum details needed for a responsible report.

Never include live API keys, passwords, private user data or complete database files in a report.
