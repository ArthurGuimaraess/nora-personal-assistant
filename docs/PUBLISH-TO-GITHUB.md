# Public repository boundary

Repository: https://github.com/ArthurGuimaraess/nora-personal-assistant

This repository is the public, limited NORA demonstration. It contains the demo source, its tests, public-facing documentation, illustrative vector previews and the automation needed to test the demo.

The complete NORA application is maintained separately and is not part of this repository. Do not copy its source code, private integrations, deployment configuration, user data, databases, backups, credentials, certificates or internal development reports into this public project.

The public demo has no authentication and must remain bound to the local machine for evaluation. See [the open-source scope](OPEN-SOURCE-SCOPE.md) and [publication checklist](PUBLICATION-CHECKLIST.md).
