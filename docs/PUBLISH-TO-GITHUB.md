# NORA repository

Repository: https://github.com/ArthurGuimaraess/nora-personal-assistant

This repository contains selected public materials, a local-only demonstration, and documentation about NORA's purpose, architecture, development history, inclusion principles and limitations.

The full private application is not included. Never add .env, API keys, certificates, databases, backups, user exports, photos or private logs. The demo has no authentication and must remain local-only.
